# Artifact Hub KEDA scaler metadata

This directory is an Artifact Hub repository of kind **KEDA Scalers**. The
current published package metadata is under `replicasense/0.3.2`.

To publish it, add this Git repository to Artifact Hub as a **KEDA Scalers**
repository using:

```text
https://github.com/canberkturan/keda-replica-sense/artifacthub
```

Select the `main` branch. Artifact Hub indexes each version directory and makes
the package available through its KEDA scaler catalog, which KEDA links to as
its external-scaler community. Keep a versioned `artifacthub-pkg.yml` and
README directory for every new release.
